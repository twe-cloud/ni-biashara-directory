# Ni Biashara Directory

Find African and Caribbean diaspora businesses across the US, Canada and beyond — Ethiopian restaurants in Silver Spring, hair braiders in Houston, Jamaican caterers in Toronto, African grocers, Nigerian tailors, coffee roasters, shippers and more.

Ni Biashara is a live, verified diaspora business directory covering 131 metros. This plugin connects Claude to that directory and teaches it how to search well, so you get real listings with phone numbers, websites, and listing pages — never invented details.

## What you get

- **Connector**: the Ni Biashara Directory MCP server with three read-only tools — `search_directory` (find businesses by keyword, city, metro, or category), `get_business` (full public listing details), and `directory_facets` (live coverage counts by metro and category).
- **Skill**: a guided search playbook that helps Claude choose the right tool, broaden weak queries, and present results with contact details and claim status.

## Example prompts

- "Find Ethiopian restaurants in Silver Spring"
- "Who does African hair braiding in Houston?"
- "Which metros have the most diaspora businesses?"

The directory is read-only: it returns public business information only, and every listing links back to nibiashara.com so owners can claim their page free.
